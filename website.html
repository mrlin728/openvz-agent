安装方法

WINDOWS

安装与首次启动

  1. 下载安装包和 SHA256SUMS.txt，先按下方命令核对 SHA-256。
  2. 双击 OpenVZ-Agent-Setup.exe。本 RC 未签名；若 SmartScreen 出现，确认哈希和下载来源后选择“更多信息 → 仍要运行”。
  3. 从桌面或开始菜单启动 OpenVZ Agent。
  4. 在激活页填写 DeepSeek、OpenAI、MiniMax、通义千问等受支持服务的 API Key。
MACOS

安装与芯片判断

  1. 点左上角  →“关于本机”：看到“芯片 Apple M…”选 Apple Silicon；看到“处理器 Intel”选 Intel，并先核对 SHA-256。
  2. 打开 DMG，将 OpenVZ Agent 拖入 Applications（应用程序）。
  3. 本 RC 未签名：按住 Control 点按应用并选择“打开”。若仍被拦截，到“系统设置 → 隐私与安全性”选择“仍要打开”。
  4. 按系统提示授权麦克风（仅语音功能需要），然后填写 API Key 激活。

不要把 API Key 发给第三方。凭据在打包桌面端使用系统安全存储；纯 Node 模式使用本机 AES-256-GCM 密钥文件，且不会通过设置 API 回显。

签名与 SHA-256

本次 Release 附带 SHA256SUMS.txt 和 UNSIGNED-BUILD.txt。请在下载后核对文件哈希；Release 发布流程会重新下载产物并复验。

Windows 校验

PowerShell：

Get-FileHash .\OpenVZ-Agent-Setup.exe -Algorithm SHA256

本 RC 的签名状态预期为 NotSigned：

Get-AuthenticodeSignature .\OpenVZ-Agent-Setup.exe

macOS 校验

终端（Intel 版把 arm64 改成 x64）：

shasum -a 256 OpenVZ-Agent-mac-arm64.dmg

spctl --assess 拒绝本未签名 RC 属于预期；请使用上方系统界面步骤，不要全局关闭 Gatekeeper。

常见问题

macOS 提示无法打开或开发者无法验证怎么办？

这是未签名 RC 的预期提示。先确认文件来自本页的 GitHub Release 并核对 SHA-256，然后按住 Control 点按应用选择“打开”；若仍被拦截，到“系统设置 → 隐私与安全性”点“仍要打开”。不要全局关闭 Gatekeeper，也不要运行下载的绕过脚本。

Windows SmartScreen 提示“Windows 已保护你的电脑”怎么办？

先确认安装包来自本页并核对 SHA-256。确认无误后点“更多信息 → 仍要运行”。本 RC 的 Get-AuthenticodeSignature 状态应为 NotSigned；正式 v2.2.0 会恢复强制签名。

没有 API Key 能使用吗？

桌面和本地数据功能可以启动，但 AI 对话与多数智能能力需要至少一个受支持模型服务商的 API Key。模型费用由相应服务商收取。

升级会丢失聊天、工作流或 MCP 配置吗？

不会。2.2.0 在原地迁移前自动创建版本化备份，并保留数据库、配置、工作流、MCP 和媒体数据。卸载程序默认也不删除用户数据。

为什么浏览器功能不需要另装 Chrome？

安装包携带与当前版本匹配的 Playwright Chromium。OpenVZ Agent 仍可优先使用本机受支持浏览器，但离线 Chromium 会作为可靠回退。
